Error typology — answer with exactly ONE label. The first seven labels distinguish fine-grained mechanisms of wrong equivalent selection; the following six each group several related mechanisms. The examples are illustrative only: NEVER assume the current item contains the same error as an example it superficially resembles; judge the actual strings of the pair under evaluation.
- wrong_related_term        : the target is a term that exists in the {domain} domain but denotes a neighbouring concept, not the one named by the English term (e.g. for "tremor" the MT output "tremblement de terre" names a different concept, the earthquake; expected: "trémor"). - paraphrase_not_term       : the target replaces the established term with a descriptive multi-word paraphrase in general language (e.g. for "lithospheric mantle" the MT output "couche profonde sous la croûte terrestre" is a description, not the term; expected: "manteau lithosphérique").

- general_word_not_term     : a single general-language word used instead of the specialised term — unlike paraphrase_not_term, one lexical unit rather than a descriptive phrase (e.g. for "repeaters" the MT output "répétiteurs" is a general-language word with no terminological value; expected: "séismes répétitifs").
